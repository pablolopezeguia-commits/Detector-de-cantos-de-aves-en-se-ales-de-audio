# Modelos SVM

Artefactos finales de la familia SVM:

| Archivo | Modelo |
| --- | --- |
| `svm_base_final.joblib` | SVM base final con 20 rasgos |
| `svm_conservative_centroid.joblib` | SVM-conservador con distancia al centroide positivo |
| `svm_augmented.joblib` | SVM-aumentado con entrenamiento aumentado |
| `svm_calibrated.joblib` | SVM calibrado |
| `svm_sensitive.joblib` | SVM-sensible con umbral orientado a recall |

Cada bundle contiene modelo, escalador, contrato de rasgos y metadatos asociados.
