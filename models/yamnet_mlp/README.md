# Modelo YAMNet+MLP

El modelo operativo está empaquetado dentro de EcoCanto:

```text
src/birdsong_detector/ecocanto/model/
├─ metadata.json
├─ yamnet_final_mlp.keras
└─ yamnet_base/
```

Se mantiene dentro del paquete para que la aplicación pueda localizarlo tanto desde el código fuente como desde una instalación editable.
